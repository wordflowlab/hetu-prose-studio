# 架构与领域设计

```mermaid
flowchart LR
 A[作者与 Codex] --> M[河图稳定 CLI/MCP]
 M --> P[TypeScript 专业应用]
 P --> D[纯领域规则]
 P --> S[公开 SDK]
 S --> C[Rust Core 固定来源与受管事务]
 V[React 专业工作面] --> M
 K[包内 Skill] --> A
```

UI 与 CLI/MCP 消费同一应用动作；视图不拥有正文数据库。Core 以当前 WorkRef、插件 Owner、固定来源、CAS 和原操作持久化专业修订。插件不保存管理授权、密钥或运行时 Context。

```mermaid
sequenceDiagram
 participant A as Codex
 participant H as 河图机器入口
 participant P as 专业应用
 participant C as Core
 A->>H: 能力发现与 Skill 读取
 A->>H: 固定作品、来源与操作
 H->>P: 校验 Schema 与专业不变量
 P->>C: 回读原操作；核对固定来源
 C-->>P: 原结果或 not_found
 P->>C: CAS 保存专业对象
 C-->>A: 固定修订、摘要及原操作回执
```

领域对象保存在宿主受管文件中。索引为可重建投影，不新建第二份正文或私有数据库。停用和卸载停止新调用，历史由宿主通用导出继续保留。

## 核心能力适配审查

| 依赖 | 当前源码入口 | 本插件验收要求 |
| --- | --- | --- |
| 作品及正式目录 | `hetu.novels.snapshot` | 当前小说统计与身份，不推断正文已读 |
| 固定文稿及设定 | `hetu.extensions.sources.inspect` | 真实字节、摘要与实体身份一致 |
| 不可变候选 | `hetu.drafts.get`及其证据文稿 | 未采纳候选可以作为固定来源，不要求改变正式正文 |
| 正文创作与返工 | 宿主任务／参考稿用例 | 外部Agent获得确切任务后提交；不得由插件请求扩权 |
| 作者意见 | 宿主task_feedback | 公开意见与专业偏好关系分开；私密批注不自动暴露 |
| 专业数据 | `hetu.extensions.objects.*` | Owner、CAS、固定历史、同键异输入及响应丢失恢复 |

源码出现不等于当前安装可用。先通过真实稳定入口核对能力与结果；若核心缺少候选来源或反馈接续，修复实际Owner并补齐Schema、CLI/MCP、Skill及测试，然后再推进插件。
