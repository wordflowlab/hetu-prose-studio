# 界面与交互设计

## 1. 工作面

使用宿主独立插件工作面，返回入口合入紧凑工具栏；打开时宿主项目导航退出工作面，不再套第二层框。顶部保留作品名、方案选择、当前修订、让AI继续、返回，历史与导出按需展开。

工作面包含“偏好”“比较”“精修”“上下文”四个任务页签。默认打开最近使用的任务与方案，不以空表单为首页；无数据时说明缺少的成果，并提供携带当前作品与任务目标的AI交接。

## 2. 专业表达

| 页面 | 主体 | 作者操作 |
| --- | --- | --- |
| 偏好 | 规则文字、作用范围、状态、来源和冲突 | 查看依据、编辑、停用／恢复、移除 |
| 比较 | 候选并排阅读；单独显示叙事差异与代价 | 选择候选或选段反馈，继续返工 |
| 精修 | 固定原文与候选差异；高亮允许范围 | 查看越界变化、提出意见、跳宿主参考稿 |
| 上下文 | 选用规则、必要资料、预算和遗漏项 | 调整本次选择、导出专业包、让AI补读 |

来源先显示作品、章节和引文，可展开修订及技术定位。规则不显示臆造“匹配率”；Agent建议与作者声明采用明确标签。正文采纳入口使用宿主已有决定旅程，不自造插件确认按钮冒充作者权限。

## 3. 状态与恢复

加载保持布局；空状态只说明下一步；错误就地显示可重试读取。保存中禁用重复提交，未知结果保留原键和输入并提供回读；冲突保留两份内容，不用刷新覆盖。离开前保存本机恢复稿，恢复稿不当作已保存作品。

## 4. 视觉与验证

遵循宿主hetu-ui-style及共享Radix语义色板，连续轻透渐变背景、稳定正文纸面、0.5px边框、默认无动画。控件使用12／14／20px三档，正文18px或用户偏好；窄窗改为单列切换对照，关键状态不能消失。

实际Electron验证浅暗、宽窄、长文本、键盘、未保存稿、冲突与unknown；视觉按布局、间距对齐、排版、颜色、状态和交互六项复核。评分是有依据的设计判断，不冒充像素认证。
