# 开发发布与上架

独立包为TypeScript专业层、React工作面、受管Node后端及同包Skill。构建将公开SDK与色板快照、领域逻辑、实际依赖和许可一起打包，用户安装时不执行npm安装或构建脚本。

发行前依次完成类型检查、领域与应用测试、真实CLI/MCP、Electron及视觉复核；再固定源码提交、SemVer、归档摘要和宿主包摘要。GitHub仓库、Tag、Release制品与插件中心条目分别校验，不以页面存在代表安装通过。

宿主机器能力、公共SDK、CLI/MCP或任务连接存在缺口时，在宿主修复并同步其合同、方法、地图与回归；不把缺口藏在插件私有HTTP、路径直写或GUI自动化里。公开SDK变更以宿主为Owner。

正式上架按河图插件23／24执行：可下载固定运行包、完整许可、CAPABILITIES、作者指南、开发文档、兼容与验收范围。发布后重新下载制品，在隔离注册表安装、使用、停用、重启用及卸载；核对官网中英文目录和链接。

已发行ID＋版本字节不可替换。更新显式选择固定包，Schema迁移单独核对；卸载不删除作品和专业历史。包退回、专业数据恢复和正文作者决定分别处理。
